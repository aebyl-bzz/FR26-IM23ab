# URL-Shortener

Eine einfache Web-Applikation, die lange URLs zu kurzen Links verkürzt.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Datenbank:** SQLite (sql.js)

## Installation

```bash
npm install
npm start
```

Der Server läuft dann auf [http://localhost:3000](http://localhost:3000).

## Features

- URL kürzen
- Automatische Weiterleitung beim Aufrufen des Kurzlinks
- URL-Validierung mit Fehlermeldungen
- Kopier-Button für den Kurzlink
